| Разрешение на работу с устройством | **НЕ ПОЛУЧЕНО** |

## Цель

Спроектировать минимальный systemless-механизм, который можно включить, проверить и полностью откатить без изменения разделов, системных APK и настроек безопасности.

## В объём входит

- Выбор способа доставки под фактический root-менеджер из C1.
- Структура будущего модуля и точки входа.
- Модель состояния, идемпотентность и dry-run.
- Контракт отката и обработка конфликтов с OTA/другими модулями.

## В объём не входит

- Фактическая установка модуля на устройство.
- Подбор визуальных ресурсов (C3).
- Выполнение тестов (C4).

## Ограничения проектирования

| Ограничение | Требование |
| --- | --- |
| Расположение | Только каталог модуля root-менеджера, например `/data/adb/modules/<id>/` |
| Разделы | `/system`, `/vendor`, `/boot`, `/data` вне каталога модуля — без записи |
| Системные APK | Не заменять, не удалять, не переподписывать |
| Безопасность | Не трогать SELinux, Verified Boot, загрузчик, A11y, device admin |
| Состояние | Хранить только собственные метаданные и хеши своих артефактов |
| Откат | Отключение → удаление каталога модуля → перезагрузка = сток |
| Сеть | Модуль не должен требовать сетевые разрешения без отдельного обоснования |

## Контракт обратимости (черновик)

| Действие | Ожидаемый эффект | След отката |
| --- | --- | --- |
| `apply` | Монтируются только собственные overlay модуля | Удаляются при `revert` |
| `dry-run` | Печать плана без изменений | Нет |
| `revert` | Снятие своих overlay | Возврат исходного состояния |
| Disable в root-менеджере | Модуль не загружается после перезагрузки | Каталог остаётся до удаления |
| Uninstall | Удаляется только каталог модуля | Нет чужих файлов |

> Таблица — проектное намерение, не выполненная проверка.

## Политика доказательств

- Не использовать статус `DONE` для механизмов, не проверенных на устройстве.
- `REPORT.md` не создаётся. Результаты — только в блоке ниже.

## Критерии остановки

- Нет фактического root-менеджера из C1 → не выбирать конкретную точку входа.
- Механизм требует записи в системный раздел → отклонить.
- Механизм требует изменения настроек безопасности → отклонить.
- Нет гарантии удаления всех созданных файлов → отклонить.
