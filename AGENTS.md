# OpenCode project rules

- Use the current task file as the source of truth.
- Read only the files explicitly needed for the task.
- Do not scan the entire repository unless requested.
- Do not repeat completed checks.
- Make the smallest necessary changes.
- Do not modify phone partitions, boot images, security settings, or thermal protections.
- Do not install anything on the phone.
- Do not create reports unless explicitly requested.
- After work, show changed files, validation results, and git status.
- Never commit or push unless explicitly requested.
